# Archived Analysis & Run-Specific Tools

This directory contains one-off analysis scripts, specific run inspectors, and historical experiment utilities preserved for research reproducibility.

## Archived Scripts
- `analyze_run_9tvq8qld.py` & `analyze_run_o6s4pex3.py`: Run-specific trajectory analysis.
- `check_per_class_trend.py`: Per-class Dice progression for specific runs.
- `compare_trajectories.py`: Specific run trajectory comparisons.
- `crawl_kaggle.py` & `crawl_run.py`: Ad-hoc kernel output crawling utilities.
- `fetch_latest_run.py`, `fetch_wandb.py`, `inspect_wandb_runs.py`, `list_runs_summary.py`: Historical W&B inspection scripts.
- `bhsd_eda_vi.py`: Vietnamese-labeled exploratory plot generator.

For active multi-run evaluation and complexity profiling, use `evaluate.py` and `tools/profile_model.py`.
